# 手账风旅行报告 prompt

旅行结束后，根据会话里已有的行程，写一段交给 ChatGPT 图像生成（或其他图像模型）的英文 prompt，让它画出一张手账风的旅行报告：竖版一页，水彩加钢笔线稿，手写体文字，纸胶带、邮票、票根。

这个技能只写 prompt，不生成图片，也不规划行程。

## 默认规则

用户另外指定了语言或风格时，以用户为准。

| 项目 | 默认 |
|---|---|
| prompt 本身 | 英文写说明，要画在图上的文字用原文写进引号里 |
| 主体文字 | 日语：标题、景点名（片假名或汉字）、感想、美食、小卡片 |
| 景点名 | 日语名下面附当地语言名，原文字母和变音符要准（见下文「当地文字」） |
| 页面设计 | 用目的地的当地特色纹样和工艺，从 4–6 个具体元素里取（见下文「挑当地特色设计」） |
| 其他 | 配色、插画角度、小涂鸦、邮票文字等自由发挥 |

## 工作流程

1. **从会话里收集素材。** 目的地、日期、路线顺序、去过的景点、吃过的东西、交通方式、同行的人、天气和意外（下雨、看到彩虹、朋友先走）。素材越具体，感想越不像套话。会话里没有的不要编；缺一两项可以用常识补全插画内容，但感想里写的经历必须是会话里有的。
2. **挑景点。** 8–10 个面板为宜（见「注意事项」）。相近的几个点合成一个面板，例如北岸三个浪点合成「ノースショア」一个大面板、里面三个小图。最有代表性的那一个给最大的面板。
3. **挑当地特色设计。** 见下节，写 4–6 条具体元素。
4. **按模板写 prompt。** 模板在 `references/template.md`，完整示例在 `examples/hawaii-oahu.md`。
5. **交付。** 把 prompt 放在一个代码块里给用户，后面附两三条用法提示：字太多出错时怎么拆页、想换风格时删哪一行换成什么。

## 版面结构

来自用户以前生成的三张样例（阿克套、2026 GW 中亚、格鲁吉亚）的共同点，样例图不在仓库里：

- **整体**：竖版 A4（2:3），米色纸底，水彩插画加钢笔线稿，日语手写体，纸胶带、邮票、圆形邮戳、车票票根和小涂鸦，排得满但有条理，像真的旅行手帐。
- **顶部**：大标题（日语，如「ジョージア旅の手帳」「アクタウへ」）加一行罗马字或当地文字副标题和日期；一句引言；一张手绘地图，虚线画出路线，各站用日语和当地文字标注，路线上画交通工具（车、火车）。
- **景点面板**：每个景点一个面板 = 水彩插画 + 日语名 + 当地语言名 + 2–3 行第一人称过去式感想。名字常写在牛皮纸标签或纸胶带上。城市名做大标题、城市里的景点做小标题，也是常见的分层方式。
- **美食区**：一个小标题（如「ジョージアのごはん」「食べたものたち」），3–4 道菜，每道 = 插画 + 日语名 + 当地名 + 一句感想。
- **小卡片**：「旅メモ」勾选清单（3–4 条旅途中的小发现）；「旅のまとめ」收尾卡片（两三句总结，最后一句常是「また来たい」或当地语言的谢谢）。
- **票根和邮票**：机票或火车票票根（航段、日期），一枚邮票（「ALOHA from HAWAIʻI 2026」这类），一个圆形邮戳（地名 · 月份）。
- **装饰**：边框、角花、面板底纹用当地纹样——中亚是伊斯兰蓝色瓷砖纹，格鲁吉亚是葡萄藤和葡萄串，哈萨克是传统卷角纹饰。空白处有当地的小动物或小物件涂鸦（骆驼、睡着的狗、海鸥）。

## 挑当地特色设计

写 "local style" 或 "Hawaiian style" 这类泛泛的词，图像模型只会画出最俗套的版本。要从下面几个来源里挑 **4–6 个具体元素**，每条写清楚画什么、用在页面哪里、什么颜色：

| 来源 | 例子 | 适合用在 |
|---|---|---|
| 织物 | 夏威夷 kapa（树皮布）几何纹、乌兹别克 ikat（扎染丝绸）、哈萨克毛毡 syrmak | 边框、面板底纹 |
| 纹样 | 夏威夷拼布（kapa kuiki）的面包树叶剪纸纹、哈萨克羊角纹（qoshqar müiiz）、格鲁吉亚葡萄藤 | 角花、分隔线 |
| 建筑装饰 | 撒马尔罕的蓝色马赛克瓷砖、格鲁吉亚教堂的石雕十字、日本寺社的唐草纹 | 边框、标题底板 |
| 复古海报和印刷品 | 1950 年代夏威夷旅游海报、苏联时期的旅游海报、当地老邮票 | 标题字体、邮票、票根 |
| 小物和动植物 | 花环（lei）、海龟（honu）、骆驼、葡萄酒罐（qvevri）、茶碗 | 页边小涂鸦 |

再加一行配色（4–6 个颜色，取自当地的海、土、建筑、织物），图会统一很多。

挑元素时注意：宗教符号只用作建筑装饰，不当成随手的贴纸；不要用带有政治含义或当地人可能觉得冒犯的图案；没把握的纹样宁可换一个常见的。

## 当地文字

景点名的当地语言写法要逐字核对，图像模型会照抄 prompt 里的拼写，错了就印在图上。

| 地区 | 要注意的 |
|---|---|
| 夏威夷 | ʻokina（ʻ，U+02BB，不是普通撇号）和 kahakō（长音符：ā ē ī ō ū），如 Waikīkī、Haleʻiwa、Lēʻahi |
| 格鲁吉亚 | 格鲁吉亚字母（Mkhedruli），如 თბილისი、მცხეთა；日常书写不分大小写 |
| 哈萨克斯坦 | 哈萨克西里尔字母里的 Қ қ、Ұ ұ、Ү ү、Ә ә、Ө ө、Ң ң、Ғ ғ、І і，如 Бозжыра、Қызылқұп |
| 乌兹别克斯坦 | 现行拉丁字母里的 oʻ、gʻ（同样用 ʻ），如 Buxoro、Samarqand |

在 prompt 末尾加一句要求保持这些字母和变音符原样。地名的当地写法查不到可靠来源时，宁可只写日语名加罗马字，不要猜。

## 注意事项

- **字数上限。** 图像模型在一张图里能正确写出的文字有限，字越多越容易出现错字、乱码、文字重叠。景点面板 8–10 个为宜，每段感想 2–3 行；超过就分两页（例如前半程一页，后半程加美食一页），每页单独一段 prompt，标题写「旅の手帳 1/2」「2/2」，版式和配色保持一致。
- **感想写法。** 第一人称过去式（「〜した」「〜だった」），写具体细节：几点、看到了什么、发生了什么（「朝6時、クレーターの縁で日の出を待った」）。不要写「とても楽しかった」「最高の思い出」这类放在哪里都成立的套话。感叹号全页控制在几处。
- **战争、宗教场所。** 纪念馆、战场、墓地的面板用安静、低饱和的颜色，感想克制（「静かな海の下に、今も眠る人たちがいる」），不写「楽しかった」，不加嬉闹的涂鸦和表情。宗教场所写建筑和气氛，不评价信仰。
- **事实。** 日期、航班号、店名要和会话里一致；图上会印出来的数字少写为妙。
- **人像。** 不要求画出用户或同行者的真实相貌；需要人物时写成背影或小人剪影。
- **最后一句。** prompt 末尾固定要求：日语文字清晰正确、当地文字保持变音符、没有文字重叠或被页边裁掉。
